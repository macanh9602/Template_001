# Grid Outer Wall Demo

1. Add `OuterWallGenerator` to an empty GameObject.
2. Choose `GridRect` and set Width/Height/Cell Size for a rectangular board wall.
3. Choose `GridMask` and fill `Occupied Cells` with cells such as `(0,0), (1,0), (1,1), (2,1)` for an irregular outline.
4. Press `Build`.

This sample is intentionally asset-free so the helper can be copied into any grid game without dependencies.
